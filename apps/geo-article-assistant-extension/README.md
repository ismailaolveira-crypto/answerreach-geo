# GEO 文章助手

平台原生的 Chrome Manifest V3 扩展。它只把已在 GEO 平台中完成人工审核的内容写入目标平台草稿箱，不执行发布。

## 本地安装

1. 在 GEO 平台下载扩展包并解压。
2. 在 Chrome/EgoLite 打开扩展管理页。
3. 启用开发者模式。
4. 选择“加载已解压的扩展程序”，并选择解压后的目录。
5. 刷新 GEO 平台，在“管理 → Agent 与交付”执行真实检测。

安装后点击浏览器工具栏中的“GEO 文章助手”，可在独立弹窗中查看各平台是否已登录、需要授权或检测失败。点击“管理平台”可进入 18 个内容平台的独立目录，按需一键添加或移除。

## 已审核配图

- GEO 后端只会把通过人工审核、文件完整性校验的图片交给扩展。
- 扩展使用 10 分钟内有效的任务地址取图，不读取 GEO 登录 Cookie。
- 图片会按审核时确定的位置插入正文，图注与图片一起写入。
- 目标平台有图床时，先上传到该平台再创建草稿；上传失败则整个平台写入失败，不会存成缺图草稿。

## 权限原则

- 默认仅申请 GEO 本地页面和五个 P0 平台的明确域名；其他平台只在用户点击“添加”时申请对应域名权限。
- 不申请全站、下载、右键菜单或无限存储权限。仅哔哩哔哩、语雀、搜狐号、博客园、东方财富的上游草稿接口需要读取对应域名的防伪 Cookie；该权限在添加平台时单独请求，不回传 Cookie 内容。
- `storage` 只保存最多 100 条本机草稿回执，用于在回传断网时阻止重复创建；不保存正文、Cookie 或平台令牌。
- 登录态只被目标平台请求使用，不会发给 GEO API。
- 弹窗只展示平台名称、登录结果和平台返回的账号显示名，不读取密码、Cookie 内容或本地存储中的凭据。

## 本地验证

```bash
node apps/geo-article-assistant-extension/tests/smoke.mjs
```

该测试使用完全模拟的平台响应，不会连接真实账号，也不会创建真实草稿；它会覆盖账号识别、四个平台草稿回链、已审核图片与图注插入、未审核图片拦截、重复写入拦截、CSDN 授权阻断、任务过期和不安全图片地址拦截。
