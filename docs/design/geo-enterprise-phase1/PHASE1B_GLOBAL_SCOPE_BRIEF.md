# Phase 1B 全局范围栏功能简报

## 真实业务问题

用户在决策、信源、竞品、问题、行动和效果页之间切换时，不能失去当前的时间、批次、模型和问题口径。这个组件只负责让范围“看得见、选得准、带得走”，不重做任何原页面。

## P0 状态

1. 桌面默认紧凑栏：时间、批次、模型、问题和同源摘要。
2. 多选展开：批次、模型、问题分组搜索与勾选，只有一个主操作“应用”。
3. 自定义日期与修正通知：无效参数被移除时明确告知，不伪装成全部已应用。
4. 部分支持：页面不支持批次等维度时直接说明。
5. 移动工作表：单行摘要入口，底部工作表分组编辑，安全区内固定取消与应用。

## 不可越界

- 不改写决策、信源、竞品和问题页的内容布局。
- 不使用各页各自的范围状态。
- 不用字母方块伪造模型 Logo。
- 不把不支持的维度静默忽略。
- 不在用户应用前把展开态草稿写入 URL。

## 实现门禁

本简报对应设计稿获得用户明确方向确认前，不修改产品代码。
