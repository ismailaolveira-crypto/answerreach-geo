# 登录页轮播卡片设计稿

用途：登录页左侧的自动轮播案例卡。视觉参考为 Webflow 注册页的案例卡结构，但所有内容、界面和品牌表达均为春秋元泉 GEO 原创。

## 共用骨架

- 画幅：竖版 4:5；深石墨外壳，细钴蓝描边与低强度蓝色外发光。
- 顶部 18%：`春秋元泉 GEO` 品牌标识区，模块名使用白色无衬线字。
- 中间 63%：蓝白色、真实可用感的 Web 工作台截图；留有清晰侧栏、工具栏、数据主体和选中态。
- 底部 19%：一条细分隔线，左侧为 1 个大号信息词，右侧为一句能力说明；不使用虚构百分比、用户数或效果承诺。
- 文字：中文为主，英文仅用于小号模块标识。生成图中文字须准确、清晰，不能出现乱码或替代文字。

## 动效规则

- 五张卡片在两端之间连续来回滚动，展示窗口仅露出其中两至三张，形成从左至右、再从右至左的移动感。
- 鼠标悬停或键盘聚焦时暂停；启用“减少动态效果”时关闭全部自动动画。
- 登录区固定为右侧白色画布，左侧不再使用大标题、英文副标题或说明文案；卡片本身承担全部产品介绍。
