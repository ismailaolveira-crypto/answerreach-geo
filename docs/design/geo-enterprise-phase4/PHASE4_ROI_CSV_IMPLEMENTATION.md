# Phase 4 · ROI CSV 批量导入实现说明

## 用户完成的事

1. 下载标准 CSV 模板。
2. 填入成本、AI 引荐访问、线索、商机和已成交数据。
3. 上传后先看预检结果，修正错误或确认导入。
4. 在 ROI 页直接查看投入、归因收入、净回报、ROI 和行动对比。
5. 如果批次有误，通过“撤销批次”生成冲销记录，原数据仍可追溯。

## 数据规则

- 每行必须有稳定的 `record_id`，相同文件或相同记录重复上传不会重复记账。
- `amount` 和 `quantity` 只能填一个。
- 成本使用金额；访问、线索、商机使用数量。
- 直接成交必须关联具体行动，来源必须是 CRM 或财务，且凭证编号不能为空。
- CSV 公式注入、异常时间、不支持的币种、跨工作区行动和缺失字段会被拦截。
- 单文件最多 5000 行、2MB。
- 多币种分开展示，不使用伪造汇率强行合并。

## 真实写入与证据

- 预检批次、每行状态、字段对应、错误原因和确认时间都写入数据库。
- 用户点击确认前，不会新增业务指标记录。
- 确认后每条记录保留批次 ID、原始记录 ID、来源、凭证和创建人。
- 导入、确认和撤销都写入审计日志。

## 验收标准

- 标准模板可下载。
- 预检能区分有效、错误和重复记录。
- 错误清单可下载。
- 同一文件、同一 `record_id` 重复操作不会重复记账。
- 撤销只新增冲销记录，不删除原记录。
- `pnpm run check:web`、生产构建、ROI API 测试、数据库迁移验证和真实浏览器验收通过。
