# Phase 5 · GEO 文章助手实现记录

## 实现形态

GEO 主平台与浏览器扩展是两个独立边界：

1. 主平台创建分发记录，仅选择已审核平台稿。
2. API 签发十分钟有效、只能使用一次的 `geo-article-assistant.v1` 任务。
3. 扩展使用本机浏览器现有登录态写入草稿，不向 GEO API 传输 Cookie 或平台令牌。
4. 扩展只返回逐平台的成功/失败与草稿链接。
5. 用户打开草稿并确认正文真实可见后，系统才记录 `draft_saved`。

## 安全与一致性

- 数据库只保存任务 Token 的 SHA-256，不保存原文。
- 任务绑定发起用户、分发批次、内容指纹、平台范围和过期时间。
- 人工审核后内容若发生变化，旧任务拒绝回传。
- 回传后 Token 立即作废，防止重放。
- 扩展在真正调用平台前先保存本机“写入中”标记，成功后保存草稿编号与地址；GEO 回传失败后重试会复用原草稿，不会再次创建。
- 本机防重复回执最多保留 100 条，不含正文、Cookie、平台令牌或账号凭证。
- 健康检查必须返回 `draftReceiptVersion: 1`；旧扩展即使协议版本相同也会被提示升级，不会被误判为可安全写入。
- 实现没有 `publish` 方法，扩展 manifest 没有 `<all_urls>`、cookies、downloads、contextMenus 或 unlimitedStorage 权限。

## 开源边界

扩展目录 `apps/geo-article-assistant-extension` 是独立 GPL-3.0 工件，保留上游 Wechatsync 许可和修改说明。主平台不嵌入 GPL 扩展代码，只通过版本化页面消息协议交互。
